# Awenia 4.0

Awenia es una aplicación local para administrar un emprendimiento de crochet: productos, materiales, proveedores, inventario, ventas, Caja, gastos, pedidos, clientes, producción, pendientes, notas, estadísticas y exportaciones.

## Desarrollo web

```powershell
npm install
npm run dev
```

## Desarrollo como aplicación Windows

```powershell
npm install
npm run desktop:dev
```

## Generar instalador `.exe`

Ejecuta:

`GENERAR_EXE.bat`

## Generar `.apk`

Ejecuta:

`GENERAR_APK.bat`

Consulta `docs/installers/README_INSTALADORES.md` antes de la primera compilación.
