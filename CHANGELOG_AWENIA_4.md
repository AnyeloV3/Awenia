# Awenia 4.0 — Desktop + Android Ready

- Se conserva la base completa de Awenia V3.1 optimizada.
- Integración de Tauri 2.11.4.
- Compilación estática de Next.js para uso sin localhost en producción.
- Bundle Windows con instalador NSIS `.exe`.
- Configuración Android para `.apk` y `.aab`.
- Recursos visuales personalizados Awenia para instalador e icono.
- Ventana desktop responsive desde 320 px de ancho.
- CSP y permisos mínimos en Tauri.
- Scripts de compilación `GENERAR_EXE.bat` y `GENERAR_APK.bat`.
- Documentación de firma y requisitos de producción.
